# Archive

Earlier work, kept because it is the record of how the project got here. None of
it is used by the app or by the scripts.

- `jeopardy-simulator-v2.html` and `jeopardy_simulator.tsx` are the two
  standalone prototypes that came before the React app. The simulation logic in
  `app/src/sim/sim-engine.ts` was ported from the first one.
- `HANDOFF.md` and `handoff doc1.txt` are notes written when the project moved
  between working sessions. Both describe prototypes, and the numbers in
  `handoff doc1.txt` are made up rather than measured, because that prototype
  used generated data to test the layout.
- `FABLE_LIFT_ANALYSIS.md` is a planning note about which remaining tasks were
  worth handing to a stronger model.

For what the project actually does now, read the README in the root folder.
